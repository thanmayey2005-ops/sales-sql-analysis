# Sales Data Analysis using SQL

## 📌 Project Overview
This project analyzes a retail sales dataset using SQL.

## 🛠 Tools Used
- MySQL Workbench
- SQL

## 📊 SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- Aggregate Functions (SUM, AVG, COUNT)
- CASE Statements
- Subqueries

## 🔎 Key Insights
- Identified top-selling products
- Determined best-performing region
- Analyzed revenue and profit trends

## 📂 Dataset
Retail sales dataset used for SQL analysis.
